# Security Policy

If you find a security issue in `ios-appstore-screenshots`, do not open a public GitHub issue first.

Report it privately by emailing `chad.newbry@gmail.com` with:

- a short description of the issue
- impact and affected workflow
- reproduction steps or proof of concept
- any suggested remediation

I will acknowledge the report, validate it, and work on a fix before public disclosure.

## Scope

Security-sensitive areas for this project include:

- template download and installation
- GitHub submission flow
- shelling out to external tools like Maestro and `gh`
- any handling of local app screenshots or project files

## Response goal

Best effort initial response target: within 72 hours.
