# Support

Use the right path based on the problem:

- Bug report: open a GitHub issue with reproduction steps, expected behavior, actual behavior, and your macOS + Swift version
- Install/setup question: open a GitHub issue and include the exact command you ran plus the full error output
- Security issue: follow [SECURITY.md](./SECURITY.md) and report it privately

## Useful details to include

- `ios-appstore-screenshots --help`
- how you installed the tool
- whether you are using templates, Maestro, or the GitHub PR flow
- the path structure under your app project's `App-Store-Screenshots/`
- the exact error output, not a paraphrase

If the problem involves Maestro, include the relevant parts of `maestro/capture-screenshots.yaml`.
